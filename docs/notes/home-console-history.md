# 家用游戏机简史：平台战争如何改变游戏设计

<ArticleTags />

家用游戏机的历史经常被写成“哪台主机赢了”的年表。但对开发者更有用的视角是：**硬件、媒介、价格与平台规则如何共同决定一个时代能做什么游戏**。

前田寻之的《家用游戏机简史》以平台战争为主线，记录了从 Atari 到 PlayStation/N64 的三十年。这篇笔记不复述每台机器的参数，而是抽取对今天仍然有效的设计规律。

## 1. 平台不是硬件，而是内容、规则与渠道

早期家用机市场证明了一件事：硬件只是入口，真正决定平台生死的是软件供给与规则。

Atari VCS 的成功来自“把街机体验搬回家”，但它的失败也同样典型：

- 卡带生产门槛低，任何人都能发行；
- 没有质量审核，劣质软件泛滥；
- 玩家无法从包装判断质量，信任被消耗；
- 最终引发 1983 年的 Atari Shock，整个北美市场萎缩。

这不是“某款烂游戏”的问题，而是平台治理失败。对今天做平台、发行或 UGC 的团队同样成立：**准入规则、质量门槛与发现机制，和硬件性能一样重要**。

## 2. Famicom：性价比、第一方与授权体系

Famicom 的成功不是单点技术突破，而是组合拳：

- 价格与性能平衡，面向家庭而不是纯发烧友；
- 第一方作品建立质量标准与品牌信任；
- 授权体系控制软件供给，避免 Atari 式泛滥；
- 卡带、Disk System 等媒介扩展了存档与内容容量；
- 第三方开发者形成生态，持续供给新类型。

从设计角度看，这些变化直接扩大了游戏的可能性：

- 存档让长流程 RPG/冒险游戏成立；
- 更大容量支持更多关卡、文本与音乐；
- 手柄与电视场景定义了平台/动作游戏的输入语法；
- 授权与品牌让“续作”和“系列”成为可积累的资产。

Famicom 时代的经验是：**平台的成功会把“能做什么游戏”变成“什么游戏值得做”**。开发者的设计空间，取决于平台生态而不是单台机器的参数。

## 3. 16 位时代：性能分层与场景分化

16 位时代出现了明显的平台分化：

| 平台 | 定位 | 设计后果 |
| - | - | - |
| PC Engine | 卡带/CD 混合、日系市场 | 射击、RPG、CD 音频 |
| Mega Drive | 街机移植、速度感 | 动作、射击、体育 |
| Game Boy | 便携、低功耗 | 短会话、强可读性、耐玩 |
| Super Famicom | 综合性能、丰富色彩 | 平台、RPG、格斗 |
| Neo Geo | 街机级硬件、高价 | 格斗、街机原味 |

同一时期，“便携”成为独立的设计约束：小屏幕、低分辨率、电池寿命、单色显示，迫使开发者把信息压缩到极致。Game Boy 的胜利说明：**体验匹配场景，比参数领先更重要**。

## 4. CD-ROM：容量、音频与加载时间

CD-ROM 带来三件事：

1. 容量跃升：预渲染背景、CD 音轨、语音、FMV；
2. 成本与读取：加载时间、寻道、光盘成本；
3. 新的游戏结构：章节化、过场叙事、流式资源。

CD-ROM²、MEGA-CD 是早期的探索，PlayStation 则把 CD 与 3D 结合，改变了行业重心。设计上出现：

- 预渲染背景 + 固定镜头的冒险游戏；
- 以 CD 音轨为卖点的音乐/演出；
- 更长的加载与更复杂的资源管理；
- “光盘容量很大”并不等于“游戏更好”，加载与节奏成为新问题。

这也是今天仍然适用的规律：**存储媒介会改变游戏结构**。容量、读取速度、随机访问能力，都会影响关卡切分、叙事方式与资源预算。

## 5. 2D 到 3D：控制器与相机的重新设计

PlayStation、Sega Saturn 与 NINTENDO64 代表了三条不同的 3D 路线：

- PlayStation：CD 容量 + 3D 硬件，强调演出与第三方生态；
- Saturn：街机移植与 2D 性能，3D 能力受限；
- N64：卡带读取快、3D 硬件强，但容量受限，第三方成本高。

3D 不只是“画面多一个轴”。它重新定义了：

- **控制器**：模拟摇杆、肩键、震动，让移动与相机可以同时操作；
- **相机**：第三人称相机、锁定、碰撞与遮挡成为新的设计问题；
- **空间**：关卡从平面卷轴变成可自由探索的 3D 空间；
- **性能**：绘制距离、LOD、透明与光照预算重新分配。

Virtual Boy 则提醒另一面：技术演示不等于产品。佩戴舒适度、使用场景与内容供给任何一项不成立，硬件创新都可能失败。

## 6. 平台战争的五条设计规律

### 6.1 约束决定类型

卡带容量、手柄按键、屏幕尺寸、读取速度，会直接决定什么类型成立。先理解平台约束，再谈创意。

### 6.2 软件供给决定平台

没有第三方与持续内容，硬件参数再强也难形成生态。平台方需要治理质量、管理供给、建立发现机制。

### 6.3 价格与场景决定受众

家庭主机、便携机、街机移植、CD 机，对应不同价格带与使用场景。设计要匹配场景，而不是只追求性能。

### 6.4 媒介改变结构

卡带、光盘、硬盘、下载、流式资源，会改变关卡长度、加载节奏、叙事方式与资源管理。媒介不是中性的。

### 6.5 质量与信任是长期资产

Atari Shock 的教训不是“不要做烂游戏”，而是“平台必须让好游戏被看见，让烂游戏付代价”。评分、审核、退款、试玩与推荐机制，都是平台设计的一部分。

## 7. 对今天开发者的检查清单

- 目标平台的硬约束是什么（输入、屏幕、存储、性能、网络）？
- 这些约束会排除哪些类型，又会放大哪些类型？
- 游戏的会话长度与使用场景是否匹配？
- 媒介/加载方式是否改变了关卡与叙事结构？
- 控制器是否支持核心动词，而不是让玩家做适配？
- 平台的内容生态是否支持你的品类被看见？
- 是否把技术演示误当成了可玩产品？
- 是否为区域市场、价格与发行策略留了空间？

家用游戏机史最值得借鉴的，不是“复古情怀”，而是每一代平台如何在约束中催生新的游戏语言。理解平台为什么赢、为什么输，比记住参数表更能帮助今天的开发者做选择。
